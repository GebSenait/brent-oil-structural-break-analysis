# Data directory

| Subdirectory   | Purpose |
|----------------|---------|
| **raw**        | Unaltered inputs (Brent prices, external series). Document source and retrieval date. |
| **processed**  | Cleaned, resampled, or derived series for modeling. |
| **events**     | Curated event dataset (geopolitical, economic, OPEC) with dates and metadata. See `events/README.md`. |
